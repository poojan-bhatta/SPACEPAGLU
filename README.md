# SUNSET ORBIT

A playable 2D narrative space exploration prototype built in Godot 4.

## Project structure

- `Scenes/` - main menu and playable Moon prototype scenes
- `Scripts/` - game logic for movement, UI, dialogue, progression, and saving
- `Data/` - historical NASA discoveries and educational challenge metadata
- `README.md` - run instructions and overview

## How to run

1. Install Godot 4.x (4.3 recommended).
2. Open the folder in Godot.
3. Select `project.godot` and press F5 to run.

## Controls

- `WASD` / arrow keys: move the astronaut
- `E`: interact with nearby historical equipment
- `Enter`: confirm in dialogue or challenge prompts

## Included prototype features

- Earth-style intro menu with Start, Continue, Settings, and Credits
- Playable Moon exploration area
- Three NASA discovery sites with educational interactions
- Mission Control dialogue and story progression
- Save/load support for discovered artifacts
- End-of-demo transition hinting at the larger journey across deep space and Mars

## Notes

The prototype uses a balanced approach: a small playable narrative game with real NASA mission references and a modular structure so future Voyagers and Mars chapters can be added without rebuilding the whole project.
